# Implementation Reports

Every actionable development task, bug fix, feature, refactoring, investigation, or documentation task must create a report in this directory.

## Naming

Use sequential numbering and descriptive filenames:

`NNN-short-description.md`

Example: `001-development-environment-setup.md`

## Required Report Sections

- Task title, date, branch, and status
- Original request
- Objective and acceptance criteria
- Previous behavior
- Root cause (when applicable)
- Implementation plan
- Actual implementation
- Technical decisions
- Modified, created, and deleted files
- Important implementation details
- Automated tests and exact results
- Build and validation results
- Manual tests actually performed
- Manual testing instructions
- Risks and limitations
- Unverified assumptions
- Remaining issues
- Acceptance criteria checklist
- Recommended next steps
